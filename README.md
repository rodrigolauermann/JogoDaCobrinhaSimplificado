# JogoDaCobrinhaSimplificado
Jogo da cobrinha simples feito em java

# Classes

- Snake - posições da cobra
- Food - gera seed para maça
- Coordenada - para utilizar nas classes Snake e Food
- Board - responsável por garantir a vizualização do tabuleiro e da cobra
- Game - responsável pela lógica do jogo
- App - ponto de partida do programa
